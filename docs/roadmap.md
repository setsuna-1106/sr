# 路线图

以下是设计方向，尚未实现，不构成发布承诺。

## 组会助手

围绕同一个项目上下文连接会前准备、低干扰会中记录与会后整理：

- 会前从 state、证据与未确认项生成讨论材料。
- 会中接受自由文本、纠正与中断恢复。
- 会后导入已有转写或音视频，保留时间、来源和疑点。
- 区分真实决定、AI 建议与待确认项，先展示 state/journal 差异再按授权写入。

拟议 `sr meeting` 命令尚不存在；音视频处理、自动录音和实时转写也未实现。
